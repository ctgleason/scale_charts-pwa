User Guide

Learn the full workflow in a few minutes: pick a key, choose voicings, explore degree-based harmony, layer overlays, and build playable progressions.

Quick Start

  1. Set Root, Accidental, and Mode in the Chord Options panel to define your key center.
  2. Pick Chord type (Triad, 7th, 9th, or Hendrix) to change the harmonic color.
  3. Choose a CAGED voicing (C, A, G, E, D) to move the shape to a different neck area.
  4. Click Degree buttons (I-VII) to hear and see diatonic movement in the same key.
  5. Turn on overlays to visualize scale tones, pentatonic choices, and chord tones together.

Feature Walkthrough

Chord Options

Defines the musical context. Root + Mode set the key, Chord type sets the harmony, and Degree picks the Roman numeral within that key.

CAGED Voicing

Select C, A, G, E, or D to bias the chord toward a playable area. Extended chords may use adjacent shapes when needed for complete tones.

Overlays

Show diatonic scale degrees, key pentatonic, chord pentatonic, and chord tones. Use this to connect rhythm shapes with lead targets.

Progressions

Create reusable chord sequences with per-step degree, duration, voicing area, and extension controls. Save, import, and export your library.

Transport

Practice in time with Play, Pause, Stop, Next/Previous step controls, count-in beats, and tempo slider from 30 to 240 BPM.

Preview Fade

When a progression has multiple steps, the next chord can fade in as a visual cue before the change.
